# 2026-06-15 · v0.2.0 — 自我探索 / 写作疗愈

## 主要新功能

### 🌙 今日签（每日仪式）
- 洞察 tab 头部新按钮 "🌙 今日签"
- 540×540 暗色 sheet，24 题题库，8 类别（感激/承认/自我对话/观察/行动/问题/欣赏/释放）
- 日期 hash 选（`year*10000+month*100+day` % pool.size），同一天稳定
- **0 token 成本**（纯本地）
- 自动保存为 `## 🌙 今日签` 段到当天日记
- Gentle streak：跳过不扣分
- 完成态显示 ✓ (checkmark.seal.fill)

### ✍️ 现在写一封（自我对话信）
- 写作 tab 顶部新卡片 "🪞 写一封信"
- 5 种场景：3mo ago / released / 1yr later / person to forgive / 5yr later
- **核心原则：LLM 只起头，主体必须用户自己写**
- LLM 生成 ~80 字开场白 + 收尾（10 秒内拿到）
- 用户可点 "不，AI 帮不了，我自己来" 跳过
- 保存自动归档到今天日记，frontmatter `tags: [letter, scenario_id]`

## 技术决策

- **不污染 Frontmatter struct**：今日签 + 写信的标记走 markdown body 的 `## 段落` 而不是 frontmatter 字段
  - Frontmatter.extra 已经是 fallback，新功能不需要 schema 改动
  - 后续 DiaryScanner 检索时如果想找"今日签过的日记"，可以用 `rawContent.contains("## 🌙 今日签")` 兜底
- **LetterService 走 fallback 模板**：如果 LLM 调用失败（无 API key / 网络 / 解析），不会阻塞用户写作
- **DailyPracticeStore.UserDefaults 命名空间**：`DiaryInsight.DailyPractice.*` 前缀，和已有的 `DiaryInsight.*` 一致
- **EditorState.forLetter() 工厂**：letter 模式下 body 预填 `## 给X的信\n\n` + opening + 空白行
