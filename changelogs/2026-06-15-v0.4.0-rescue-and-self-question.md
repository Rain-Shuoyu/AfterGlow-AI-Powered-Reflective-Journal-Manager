# 2026-06-15 · v0.4.0 — 真正能干预情绪

## 主要新功能

### 🌧 情绪急救（两层级）
- **层 1: 1 行情绪记录**（3 处入口）
  - MoodQuick：4 emoji + 60 字内（不打分）
  - MoodQuickSheet：460×380 暗色 sheet
  - 持久化为 frontmatter `mood_quick: "😔 撑了一天"`
  - 3 处入口：洞察 tab / 今日签 sheet / 写作 tab
- **层 2: 情绪急救干预**
  - RescueDetector：14 天 lookback，3+ 连续低分 + 19 个关键词
  - RescueStore：7 天去重 + 每日 dismiss + 5 次自动永久关闭
  - RescueSheet：冷蓝 1-2 篇旧日记（6-12 个月前）
  - RescueBannerView：冷蓝顶部 banner
  - 洞察 tab "🌧 急救" 按钮（手动模式，disabled when signal=.none）

### 📓 自我追问
- SelfQuestion：3 类（unresolved / definition / emotion）
- SelfQuestionService：LLM 调用 + 强制 JSON 输出 + 30 天缓存
- SelfQuestionCard：写作 tab 顶部，显示前 3 个
- "写一写" 打开 EditorView 预填问题
- "看那天" 跳转源 entry
- "换一批" 强制重新跑 LLM

## 边界 / 文化敏感

- **不替代 LLM 解读**：急救 sheet 没有任何 AI 生成的"分析"或"建议"
- **不 push 通知**：所有 banner 都在 app 内，不发系统通知
- **可永久关闭**：5 次点"我不想再看到这个"自动 disable
- **冷蓝色 backdrop**：视觉信号"这不是好事"，区别于暖琥珀色的正向功能
- **关键词保守**：19 个中文关键词偏向"间接表达"（"撑不住 / 好累 / 放弃"），避免误报

## 技术决策

- **`mood_quick` 走 frontmatter.extra**：与 v0.3 写信 tags 同样的策略，不污染 Frontmatter struct
- **RescueDetector.parseMoodQuick() 复用**：MoodQuickSheet 和 RescueSheet 都用
- **SelfQuestionService 懒加载**：EditorTabView 的 `@State private var service: SelfQuestionService?`，onAppear 时构造（因为需要 env-object SettingsStore，init 不可用）
- **JSON 强制输出**：LLM 系统 prompt 强调"严格 JSON 数组，不要 markdown"，但客户端仍做 fence-stripping 防御
