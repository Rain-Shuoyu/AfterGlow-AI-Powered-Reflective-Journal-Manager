# 2026-06-15 · v0.3.0 — 让时间自己说话

## 主要新功能

### 🕯 周年回响（时间纵深）
- AnniversaryFinder：m/d 匹配过去 N 年的日记（max 5 年）
  - loose 匹配（不强制 365 天，避免闰年 off-by-one）
  - preview 抽取：每篇前 3 段，去 markdown 标记，cap 300 字
- AnniversaryStore：3 天去重 + 每日 dismiss + 永久关闭
- AnniversarySheet：620×600 暗色 sheet + 烛光晕
- AnniversaryBannerView：顶部紧凑 banner，洞察 tab 自动出现
- 洞察 tab "🕯 周年" 按钮（手动模式，不受 ±1 天窗口限制）

### 🪞 镜像回放（自我同一性）
- MirrorSampler：MMR 多样性采样算法
  - 12 篇候选池 → 贪心选 6 句
  - λ=0 = 纯多样性，6 句不撞主题
  - 随机模式（centroid anchor）+ 主题模式（工作/感情/自我）
  - 0 LLM，0 token，全部本地
- MirrorSheet：580×640 暗色 sheet
  - 主题菜单（随机/工作/感情/自我）
  - 「🎲 换一组」立即重新采样
  - 「📋 复制整段」→ NSPasteboard
- 洞察 tab "🪞 镜像" 按钮（disabled < 5 entries）

## 技术决策

- **banner 渲染时算 shouldShowBanner**：每次 `body` evaluation 都跑一次（线性扫 entries），对个人日记规模 (< 10K) 来说成本可忽略
- **MirrorSampler O(N²) 但 N=12**：可以忽略；考虑未来扩展到更大池子时换 FAISS
- **anniversaryEntries State + onChange(store.entries)**：entries 变化时自动重算，避免 stale 状态
- **3 天去重 vs 严格 anniversary window**：3 天比 ±1 天窗口稍微宽松，覆盖完整 ±1 天而不依赖具体时间
- **缺失的年份留空不补**：1 年前没写就显示"1 年前没有日记"，比强行编一篇更尊重真实
